# 个人店铺电商系统 - 前端

## 技术栈
- Vue 3 + TypeScript
- Vue Router 4
- Pinia
- Element Plus
- Axios
- Vite

## 快速开始

### 环境要求
- Node.js 18+
- npm 9+

### 构建运行
```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 项目结构
```
src/
├── views/           # 页面组件
│   ├── home/        # 首页
│   ├── product/     # 商品
│   ├── cart/        # 购物车
│   ├── order/       # 订单
│   ├── login/       # 登录注册
│   ├── profile/     # 个人中心
│   └── admin/       # 管理后台
├── components/      # 通用组件
├── stores/          # Pinia 状态管理
├── api/             # API 请求封装
├── router/          # 路由配置
├── utils/           # 工具函数
└── styles/          # 全局样式
```

## 访问地址
- 前端：http://localhost:3000
- 后端API：http://localhost:8080
- API文档：http://localhost:8080/doc.html
